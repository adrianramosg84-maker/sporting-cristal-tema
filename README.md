# ⚽ Tema Sporting Cristal - App Android

## Instrucciones para compilar y obtener el APK

### PASO 1 - Subir a GitHub
1. Ve a **github.com** e inicia sesión
2. Clic en **"New repository"**
3. Nombre: `sporting-cristal-tema`
4. Clic **"Create repository"**
5. Sube todos estos archivos arrastrándolos

### PASO 2 - Compilar automáticamente
1. En tu repositorio ve a la pestaña **"Actions"**
2. Verás el workflow **"Build Sporting Cristal APK"**
3. Clic en **"Run workflow"** → **"Run workflow"**
4. Espera 3-5 minutos

### PASO 3 - Descargar el APK
1. Cuando termine verás ✅ verde
2. Clic en el workflow completado
3. Baja hasta **"Artifacts"**
4. Descarga **"SportingCristal-APK"**
5. Extrae el ZIP → tienes el **app-debug.apk**

### PASO 4 - Instalar en tu Redmi Note 10S
1. Copia el APK a tu celular
2. En el celular ve a **Ajustes → Seguridad → Instalar apps desconocidas**
3. Permite la instalación
4. Abre el APK desde el administrador de archivos
5. Toca **Instalar**

### La app te permite:
- ✅ Aplicar fondo de pantalla Sporting Cristal
- ✅ Aplicar pantalla de bloqueo con escudo SC
- ✅ Ver el escudo y colores oficiales
